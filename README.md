# acr-docs

Documentation, Architecture Whitepapers, Integration Guides & Protocol References for the Agentic Chat Rooms (ACR) Ecosystem

## Overview
Unstructured multi-agent systems drift without shared state, verifiable signatures, and explicit human escalation gates. **acr-docs** is the official documentation repository for the **Agentic Chat Rooms (ACR)** ecosystem, covering protocol specifications, **67% Consensus Gate** voting (signed by W3C Ed25519 DIDs), **Atlas 2.0 Dynamic DAG** execution with deterministic rollbacks, **ToolHive Micro-Sandboxing** process isolation, **$0 Runtime Protocol Tax** under Apache-2.0, **WCAG 2.2 AAA COMPLIANT** interfaces, dynamic port mapping standards, and deployment guides.

## Technology Stack
- **Architecture** uses Markdown, Mermaid Diagrams, OpenAPI 3.1, and AsyncAPI specifications.
