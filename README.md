# acr-docs

Comprehensive Documentation, Architecture Whitepapers, Integration Guides & Protocol References

## Overview
**acr-docs** is the official documentation repository for the **Agentic Chat Rooms (ACR)** ecosystem — covering protocol specifications, multi-agent consensus RFCs, Meta-MCP architecture, dynamic port mapping standards, and deployment guides.

## Technology Stack
- **Architecture**: Markdown / Mermaid Diagrams / OpenAPI 3.1 / AsyncAPI
